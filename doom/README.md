# MARVEL // WORTHY

Fan-made Marvel watch-order and quiz trial. Next.js 16 + Tailwind + Framer Motion.

## Run locally
    npm install
    npm run dev

## Deploy on Vercel
1. Push this repo to GitHub (package.json must be at the repo root).
2. Import it in Vercel. Framework: Next.js. Leave Root Directory empty.
3. Optional env vars: see `.env.example`. Add the Upstash Redis integration (Storage tab) to enable the visit counter.
